Proteus Viewer

Layers

    View Proteus schematics and PCBs in your browser

    Drop files here or use Open files. Loose files or a .zip, in any combination:

    • Proteus project (.pdsprj)
      Draws the schematic, PCB top and bottom, and the parts list. No export needed.
    • Schematic: PDF, SVG or PNG
      In Proteus: File → Print to PDF, or File → Export Graphics
    • PCB: Gerber and drill files
      In Proteus: Output → Generate Gerber/Excellon Files

    Files stay on your computer. Nothing is uploaded. Keys 1–5 switch tabs, scroll to zoom, drag to pan.

    Reading .pdsprj files relies on a reverse-engineered format, so details can differ from Proteus. Exports render exactly. Source & issues on GitHub
